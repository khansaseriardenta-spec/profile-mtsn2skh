# Website MTsN 2 Sukoharjo (HTML, CSS, JS)
Buka `index.html` di browser, atau unggah seluruh folder ke hosting.

## Yang perlu diganti sebelum tayang
- **Logo**: ganti `assets/img/logo-mtsn2skh.png` dengan logo resmi (nama file sama, atau ubah path di index.html). Logo bawaan hanya placeholder.
- **Foto**: semua foto kini memakai link internet (objek `IMG` di `js/data.js` dan `index.html`). Foto robotik/gedung/outbound/futsal berasal dari berita Kemenag Jateng & Jawa Pos tentang MTsN 2; sisanya foto ilustrasi dari Wikimedia Commons. Ganti dengan link foto resmi madrasah jika sudah ada. Foto kepala madrasah belum ada link-nya, jadi bagian sambutan memakai gambar gedung.
- **Video**: video yang linknya mati otomatis disembunyikan oleh `js/main.js`.
- **Kontak**: isi telepon, email, nomor WhatsApp, dan ID video YouTube di `js/config.js`.
- **Data**: berita dan prestasi di `js/data.js` bersumber dari PRD; verifikasi dulu.

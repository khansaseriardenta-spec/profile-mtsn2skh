# Website MTsN 2 Sukoharjo (HTML, CSS, JS)
Buka `index.html` di browser, atau unggah seluruh folder ke hosting.

## Yang perlu diganti sebelum tayang
- **Logo**: ganti `assets/img/logo-mtsn2skh.svg` dengan logo resmi (nama file sama, atau ubah path di index.html). Logo bawaan hanya placeholder.
- **Foto**: semua file di `assets/img/kegiatan` dan `assets/img/lomba` adalah ilustrasi placeholder. Letakkan foto resmi (JPG/WebP) lalu ubah path di `js/data.js`. Pastikan ada izin foto siswa.
- **Kontak**: isi telepon, email, nomor WhatsApp, dan ID video YouTube di `js/config.js`.
- **Data**: berita dan prestasi di `js/data.js` bersumber dari PRD; verifikasi dulu.
